# APS Market Intelligence

Интерактивное исследование восьми рынков для stablecoin-powered global money app. Сайт объединяет открытые числовые данные, экспертные интервью, локальную конкурентную среду, условия входа, подтверждённые кейсы и каналы привлечения.

## Структура исследования

- единый рейтинг привлекательности рынка по девяти критериям и трём блокам;
- прозрачные веса, нормированные оценки 1–5 и заранее заданные ограничители;
- количественная база и качественная проверка без двойного учёта факторов;
- подробные профили восьми рынков по шести одинаковым разделам;
- глобальные и локальные конкуренты, включая частичную доступность продукта;
- независимые оценки силы потребности и сложности входа;
- подтверждённые кейсы компаний и acquisition-каналы;
- обезличенный реестр завершённых экспертных интервью;
- реестр источников с отдельной обработкой некликабельных интервью.

Итоговая оценка рассчитывается как 35% потребности в продукте + 30% коммерческого потенциала + 35% реализуемости входа. Уровень подтверждения остаётся отдельной пометкой качества доказательств и не создаёт вторую шкалу.

## Запуск и проверка

Требуется Node.js `>=22.13.0`.

```bash
npm install
npm run dev
npm run lint
npm test
npm run build:static
```

Основной набор данных находится в `app/data/market_data.json`, интерфейс — в `app/MarketDashboard.tsx`, адаптивные стили — в `app/globals.css`.
